Running on AMS · an agentic merchandising surface

The store builds
itself around you.

This is not search, and it is not a filtered grid. Tell the store what you're actually doing — a wedding on a beach, a winter work trip, a gift for someone whose taste you already know — and it composes a storefront for that. No page existed before your sentence.

Then keep talking. Every follow-up rebuilds the layout around what changed, in the same conversation. That is the part a catalogue cannot do.

01

You say what you're doing

In your own words. The occasion, the place, the season, the person — not a product name.

02

The store composes

A stylist reads the situation, picks from the real catalogue, and builds a page for it. About fifteen seconds.

03

You keep going

“Flats instead.” “Something for the reception.” The layout rearranges around each turn.

Start a conversation

Pick one and the store builds itself — nothing to type.

Guided demo · six beats

  1. Open the store. Beat one is delivered on the way in, so the opening look composes as it loads.
    1 · Open the storefront
  2. Copy the prompt. It carries the operating rules, what this kind of store is, and all six beats.
  3. Paste it into your agent, with the storefront as the active tab. Browser agents only act when a person starts them, so nothing runs until you do this.

Or drive it by hand: say each line below in the store's own composer, one at a time.

    Agents welcome. This page and the storefront both declare their tools on navigator.modelContext, so an agent can do all of the above without a browser driver. Here, list_intents and start_shopping; on the storefront, send_message and the rest of the surface. Start with how_to_use_this_site — it explains what this kind of store is and how to drive it.

    The panel in the corner lists every registered tool and logs each call as it lands, so the protocol is visible without an agent attached. Run PlaygroundWebMCP.selfCheck() in the console to see exactly which instructions reach an agent, and how. The same guide is served at /llms.txt.
